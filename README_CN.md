# 论文代码与部分汇总结果

本仓库对应《Cross-Guided Dual-Scale Learning with a Dynamic Industry Graph for Next-Day Electricity Consumption Forecasting》。

发布范围为模型与实验代码、配置、复现说明，以及最终论文表5-16的汇总结果。没有发布原始Excel、准备后的逐日数据、真实值/预测值序列、权重、论文PDF或图片。

- 两分支均回看42天，预测未来一天；96是每日15分钟功率采样点数。
- 主实验及融合对比使用五种子42、123、2024、2025、3407。
- 模块与图控制实验使用42、123、3407三个匹配种子，不能与五种子均值混用。
- 噪声实验固定模型种子42，三个噪声种子只表示扰动重复。
- 表5是初始窗口选择的验证集结果；后续对比表是测试集结果。
- 功率使用GW；电量、MAE和RMSE使用GWh；MAPE使用百分数。

论文表号与结果文件的一一对应关系见`docs/PAPER_RESULTS_MAP.md`。本次不发布旧六种子图。拥有原始数据授权的使用者，可按`docs/REPRODUCING.md`在本地复现实验；无数据授权时可检查代码、参数与汇总结果，但不能由汇总表恢复原始观测。
