# Aggregate results only

These 12 CSVs correspond to manuscript Tables 5-16. No row contains an observation-day measurement or prediction. See `../docs/PAPER_RESULTS_MAP.md` for the seed group, validation/test distinction, model aliases and scope of each table.

CSV values use manuscript precision. `*_sd` denotes sample SD across the training seeds specified for that table, except that noise metrics are averages over perturbation realizations of one fixed checkpoint. No standard deviation is fabricated for individual statistical/tree fits.
