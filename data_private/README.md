# Local private data

Place the audited `model_space.csv` and unit-audit metadata here for local runs.
The actual data and original spreadsheets are excluded from Git. See
`docs/REPRODUCING_CN.md` for the data requirements and reproduction commands;
shared physical-unit conversions are implemented in `src/hubei_revision/units.py`.
No permission to publish provincial or industry observations is implied by
creating this directory.
